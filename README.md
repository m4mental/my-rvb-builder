>
> All APKs and modules in this repository are 100% automated. If you need help, please direct your feedback to the right place:
>
> - 🧩 **Patch Issues:** If a specific feature/mod is broken (e.g., ads are showing), please open an issue in the **respective patch developer's repository**.
> - 🛠️ **Builder Issues:** If an app fails to build, or the download links are broken, **[open an Issue here on GitHub](https://github.com/m4mental/my-rvb-builder/issues)**.
> - 💬 **General Help & Requests:** Need help installing, or want to request a new app? **[Open an Issue here on GitHub](https://github.com/m4mental/my-rvb-builder/issues)** or **[open a discussion here on GitHub](https://github.com/m4mental/my-rvb-builder/discussions)**.
